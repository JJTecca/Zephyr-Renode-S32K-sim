# S32K3

NXP Cortex-M7 MCU — our **zonal hub** and the only in-vehicle AI: quantized detector +
[[safety supervisor]] + recovery actuation + cloud uplink. See [[ADR-001 — Two-tier in-vehicle topology]].

**Correction (Skills Atlas, 2026-07): S32K3 has NO NPU.** The eIQ Neutron NPU lives in MCX N,
i.MX RT700 and S32K5 — not here. Inference runs on the M7 CPU with [[int8]] + [[CMSIS-NN]].
Reframed as the stronger claim: *the detector fits a plain M7 real-time budget with no accelerator.*
The S32K5/NPU port is future work (Ch. 8). In [[Renode]] use the S32K388 model —
write “S32K3-class (S32K388)” ([[ADR-012 — Renode is the plan of record]]).
